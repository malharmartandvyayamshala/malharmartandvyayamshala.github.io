# Shri Malhar Martand Vyayam Shala — Heritage Website

Static, responsive bilingual (Hindi primary, English secondary) website.

## Pages
Home, About, History, Archives, Branches, Events, Gallery, Contact.

## Language toggle
Every text has a `.lang-hi` and a `.lang-en` sibling in the same element; CSS shows the one matching
`<html lang>`. The choice is saved in localStorage. `?lang=en` on any URL opens the English view.

## Run locally
Open `index.html` directly, or serve the folder with any static server.

## Before publishing
1. Connect Google Search Console, submit the sitemap, and link the site from the Google Business profile.

# Shri Malhar Martand Vyayam Shala — Heritage Website

Static, responsive bilingual website prototype.

## Run locally
Open `index.html` directly, or serve the folder with any static server.

## Before publishing
1. Replace `YOUR-DOMAIN.example` in `robots.txt` and `sitemap.xml`.
2. Add the final official phone number/social links.
3. Replace/expand historical copy with verified archival information.
4. Add more authentic gallery images as available.
5. Connect Google Search Console and submit the sitemap.

The language switch uses the same DOM content and stores the selected language in localStorage.
